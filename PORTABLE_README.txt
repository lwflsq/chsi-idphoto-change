学信网照片替换工具（Windows x64 便携版）
========================================

一、运行

1. 将压缩包完整解压到普通文件夹，不要直接在压缩包内运行。
2. 双击“启动.bat”或“chsi-idphoto-swap.exe”。
3. 浏览器会自动打开 http://127.0.0.1:8765 。
4. 选择照片并启动 WireGuard，然后用手机扫描网页中的二维码。

本便携版已内置 Python 和所需依赖，目标电脑不需要安装 Python。

二、新电脑首次使用

程序首次启动代理后，会在当前 Windows 用户目录的 .mitmproxy 文件夹中生成 WireGuard 密钥。换电脑后需要：

1. 删除手机中旧的 WireGuard 配置，再扫描新网页生成的二维码。
2. Windows 防火墙询问时，允许本程序访问“专用网络”。

当前照片上传链路不要求手机安装 mitmproxy CA 证书。只有以后目标接口改为 HTTPS，并明确出现证书校验错误时，才需要另行处理证书。

三、文件与隐私

上传的照片、运行日志、WireGuard 客户端配置和二维码只保存在程序所在文件夹，不包含在发布压缩包中。请在使用后自行妥善保管或删除这些运行文件。

四、常见问题

- 网页打不开：确认 8765 端口未被其他程序占用。
- 手机连不上：确认手机与电脑在同一局域网，防火墙允许专用网络，网页中的电脑 IP 地址正确。
- 换电脑后连不上：删除旧 WireGuard 隧道，扫描新电脑生成的二维码，并检查防火墙与局域网 IP。
- 退出：关闭程序的命令行窗口；程序会尝试同时停止 WireGuard 代理。
