学信网照片替换工具（Windows x64 便携版）
========================================

一、运行

1. 将压缩包完整解压到普通文件夹，不要直接在压缩包内运行。
2. 双击“启动.bat”或“chsi-idphoto-swap.exe”。
3. 浏览器会自动打开 http://127.0.0.1:8765 。
4. 选择照片并启动 WireGuard，然后用手机扫描网页中的二维码。

本便携版已内置 Python 和所需依赖，目标电脑不需要安装 Python。

二、首次使用与更换电脑

程序首次启动代理后，会在当前 Windows 用户目录的 .mitmproxy 文件夹中生成本机 CA 和 WireGuard 密钥。请完成以下设置：

1. 扫描当前网页生成的 WireGuard 二维码；如果手机里已有本项目的旧配置，请先停用或删除。
2. Windows 防火墙询问时，允许本程序访问“专用网络”。
3. 让手机信任当前电脑生成的 mitmproxy CA。

照片上传目标是 HTTPS。普通网站可以正常上网、WireGuard 也能握手，并不代表学信网 App 已经信任当前电脑的 CA。上传步骤提示无网络时，请先查看网页日志中是否有 TLS / certificate 错误。部分 Android App 不接受普通用户证书，已 root 的设备可能需要将证书加入系统信任区。

如果此前在另一台电脑上使用过本项目，也可以在程序完全退出后，把那台电脑的整个 .mitmproxy 文件夹复制到当前电脑的同一位置，以继续使用手机已经信任的 CA。

只传证书到手机时使用 .mitmproxy\mitmproxy-ca-cert.cer；不要传 mitmproxy-ca.pem，它包含 CA 私钥。复制整个 .mitmproxy 文件夹只适合在自己可信的电脑之间迁移，不能公开分享。

三、文件与隐私

上传的照片、运行日志、WireGuard 客户端配置和二维码只保存在程序所在文件夹，不包含在发布压缩包中。请在使用后自行妥善保管或删除这些运行文件。

四、常见问题

- 网页打不开：确认 8765 端口未被其他程序占用。
- 手机连不上：确认手机与电脑在同一局域网，防火墙允许专用网络，网页中的电脑 IP 地址正确。
- 更换电脑或网络后连不上：停用旧 WireGuard 隧道，扫描当前网页生成的二维码，并检查防火墙与局域网 IP。
- WireGuard 有握手且能上网，但上传时无网络：查看网页日志中的 TLS 错误，并确认手机信任当前电脑的 CA。
- 退出：关闭程序的命令行窗口；程序会尝试同时停止 WireGuard 代理。
